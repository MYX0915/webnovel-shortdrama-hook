# Android 应用分析

## 目录结构

- `编译结果/`：四个应用的原始 APK、反编译源码、Apktool 输出和反编译诊断日志。
- `scripts/`：按应用存放分析记录、运行脚本和采集数据；采集数据放在应用的 `data/` 子目录。
